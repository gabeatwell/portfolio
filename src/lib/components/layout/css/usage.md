# usage of components

## CSSscrollTEXT

```svelte
<CSSscrollText
    mainTitle="component title"
    mainSubTitle="a subtitle"
    subtitle={['different', 'text', 'subtitles']}
    text={[
        'this is a sveltekit component. you add text here..',
        'you can also add multiple text fields.',
    ]}
/>
```

## CSSparallax

```svelte
<CSSparallax image={the - image - url} />
```

With CSSparallax, the image is supposed to be positioned in the center horizontally.
